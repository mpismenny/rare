# Первый проверочный цикл

## Цель

Проверить полезность нейтральных рабочих фигур до создания финальной мифологии и визуального кода.

## Объём

- пять основных интервью;
- одно резервное интервью;
- три интервью по базовому протоколу;
- два интервью со сравнением состояния и типа;
- один необязательный возврат через неделю для участниц, которые согласятся;
- краткий общий разбор после пятого интервью.

## Решение после цикла

После пятого интервью выбрать одно:

1. переписать функции фигур;
2. развивать модель актуальных состояний;
3. проверить гибрид базовой силы и актуальной союзницы;
4. вернуться к исследованию аудитории, если язык не вызывает узнавания.

Только после этого выбирать главную метафору мира и финальные названия. Месячный обзор, групповую практику и вторую балансирующую фигуру проверять позже.
