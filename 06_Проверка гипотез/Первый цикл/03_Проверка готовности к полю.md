# Проверка готовности к полю

## Статус

Автономная подготовка завершена. Первый цикл можно запускать после подбора взрослых участниц.

## Готовность материалов

- [x] приглашение;
- [x] матрица набора;
- [x] сообщения участнице;
- [x] согласие и конфиденциальность;
- [x] гайд интервью;
- [x] скрининг;
- [x] пять нейтральных карточек;
- [x] контроль случайной карточкой;
- [x] сравнение состояния и типа;
- [x] трекер недельного возврата;
- [x] чек-лист одного разговора;
- [x] шаблон отдельного интервью;
- [x] шаблон итогов цикла;
- [x] правила изменений между интервью;
- [x] матрица различимости фигур;
- [x] необязательная проверка союзницы;

## Что требует решения перед первым приглашением

1. Кто отправляет приглашения.
2. Через какой канал связи.
3. Где хранится контакт участницы вне исследовательских заметок.
4. Нужна ли запись аудио. По умолчанию: нет.
5. Кто проводит интервью.
6. В какие даты доступны слоты.

## Что не блокирует запуск

- финальная мифология;
- визуальная система;
- тест;
- сайт;
- клуб;
- мерч;
- обучение проводников;
- автоматизация сообщений.

## Точка остановки

Без реальных участниц нельзя честно проверить:

- узнавание;
- различимость фигур;
- фактическое выполнение действия;
- комфорт недельного возврата;
- полезность символического слоя для скептического сегмента.
