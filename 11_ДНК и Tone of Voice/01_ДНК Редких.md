# ДНК Редких

## Исходная формула

> Тягучий, васильковый, медовый, при этом лёгкий и без хромоты.

Эта формула задаёт напряжение, а не набор эпитетов. Текст должен оставлять послевкусие, но не задерживать читательницу в каждой фразе.

## Обещание голоса

Редкие дают женщине пространство для внимательного узнавания себя без требования немедленно определить себя, исправить себя или доказать что-либо о себе.

## Мировоззренческие опоры

| Опора | Что это значит для текста |
|---|---|
| Вариативность | Не сводить женщину к одному типу, роли, возрасту или циклу |
| Вместимость | Допускать противоречие без спешки устранить его |
| Внимание | Сначала замечать состояние, затем предлагать действие |
| Выбор | Не выдавать символический язык за предписание |
| Ритм | Давать место повторению, паузе, возвращению и изменению |
| Достоинство | Не строить близость через унижение, страх или обещание тайного превосходства |
| Ясность | Не прятать слабую мысль за красивой формулировкой |

## Ключевые напряжения

Редакционный голос удерживает пары, не выбирая только одну сторону:

| Первая сторона | Вторая сторона |
|---|---|
| Тягучесть | Лёгкость |
| Чувственность | Точность |
| Тайна | Понятность |
| Интимность | Граница |
| Телесность | Отсутствие медицинского нажима |
| Ритуал | Свобода отказаться |
| Поэтичность | Отсутствие пафоса |

## Что Редкие не делают

- Не диагностируют.
- Не обещают судьбу, исцеление или превосходство.
- Не объявляют отдельный опыт обязательной нормой женственности.
- Не называют любую трудность знаком скрытой избранности.
- Не используют туманность как замену смыслу.
- Не требуют веры для получения права на участие.
