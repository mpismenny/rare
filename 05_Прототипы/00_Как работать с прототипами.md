# Как работать с прототипами

Прототип нужен не для красоты, а для проверки одного вопроса.

## Форматы

| Формат | Что проверяет |
|---|---|
| Карточка образа | Возникает ли узнавание и интерес |
| Короткий тест | Понятна ли точка входа |
| Выбор жизненной ситуации | Помогает ли контекст персонализировать результат |
| Практика на 5–15 минут | Хочется ли сделать следующий шаг |
| Еженедельный ритуал | Возникает ли естественный возврат |
| Групповая встреча | Работает ли общий язык |
| Физический объект | Поддерживает ли символ отношения с системой |

## Правило

Один прототип проверяет одну гипотезу из [[06_Проверка гипотез/Реестр гипотез]]. До проверки не вкладываться в сложную механику и визуальную систему.
