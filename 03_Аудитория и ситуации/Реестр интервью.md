## Правило

Для каждого разговора создавать отдельную заметку по шаблону [[Шаблоны/Интервью]]. Не записывать лишние персональные данные. Если имя не нужно для работы, использовать код участницы.

## Минимум для первого решения

- пять завершённых интервью;
- не менее трёх разных жизненных ситуаций;
- минимум два интервью со сравнением состояния и типа;
- фиксация дословных формулировок;
- отдельный разбор сигналов за и против гипотез.
