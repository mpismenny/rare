# Чек-лист одного интервью

## До разговора

- [ ] Присвоить код участницы.
- [ ] Создать заметку по [[Шаблоны/Интервью]].
- [ ] Проверить, что участница совершеннолетняя.
- [ ] Не собирать лишние персональные данные.
- [ ] Подготовить пять карточек и одну случайную контрольную карточку.
- [ ] Выбрать базовый протокол или сравнение состояния и типа.

## Перед карточками

- [ ] Проговорить согласие и конфиденциальность.
- [ ] Отдельно спросить разрешение на письменные заметки.
- [ ] Не записывать аудио без отдельной защищённой папки и согласия.
- [ ] Зафиксировать ситуацию словами участницы.
- [ ] Зафиксировать собственный шаг участницы до карточки.
- [ ] Пройти [[05_Прототипы/09_Скрининг перед показом]].
- [ ] Остановиться при красном флаге.

## Показ

- [ ] Проговорить: карточка не описывает человека и не является диагнозом.
- [ ] Разрешить выбрать «ни одна», собственный образ или отказаться.
- [ ] Не объяснять правильный выбор.
- [ ] Показать полную карточку только после выбора.
- [ ] Спросить, что точно не подходит.
- [ ] Показать случайную карточку как контроль универсальности.
- [ ] Уточнить, изменился ли следующий шаг.
- [ ] Проверить, не появилось ли давление.
- [ ] Не показывать союзницу автоматически; предложить только после согласия и только если основной выбор уже понятен.

## Завершение

- [ ] Спросить согласие на один возврат через неделю.
- [ ] Зафиксировать дословные формулировки.
- [ ] Отделить слова участницы от интерпретации исследователя.
- [ ] Отметить сигналы за и против гипотез.
- [ ] Записать одно изменение для следующего разговора.

## После разговора

- [ ] Обновить [[03_Аудитория и ситуации/Реестр интервью]].
- [ ] Отправить сообщение после интервью.
- [ ] Не менять сразу весь прототип после единичной реакции.
- [ ] После пятого интервью заполнить [[06_Проверка гипотез/Первый цикл/01_Шаблон итогов полевого цикла]].
- [ ] Соблюдать [[06_Проверка гипотез/Первый цикл/02_Правила изменений между интервью]].
