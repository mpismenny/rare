# Как добавлять книги

## Назначение

Локальная библиотека хранит книги, которые пользователь передаёт для исследования архетипов, женского опыта и смежных тем. Книги не смешиваются с готовыми выводами автоматически: каждая проходит отдельную обработку.

## Куда класть файлы

Помещать исходные файлы в папку:

`08_Источники/Библиотека книг/Входящие файлы`

Отдельные цитаты и фрагменты без полного файла сохраняются в папке:

`08_Источники/Библиотека книг/Входящие фрагменты`

Поддерживаемые рабочие форматы:

- PDF с текстовым слоем;
- EPUB;
- DOCX;
- FB2;
- DJVU, если доступен конвертер или OCR;
- TXT;
- Markdown;
- сканы PDF, если для них можно выполнить распознавание текста.

Автоматически загружать только полные тексты, которые легально распространяются открыто. Ознакомительные preview не добавлять в библиотеку: для книг под авторским правом сохранять библиографическую карточку и ждать приобретённый пользователем файл.

## Конвейер обработки

1. Добавить книгу в [[08_Источники/Библиотека книг/00_Каталог книг]].
2. Создать паспорт по [[Шаблоны/Книга]].
3. Проверить автора, название, издание, год и доступность страниц.
4. Составить оглавление и карту релевантных глав.
5. Сделать конспект по темам с точными страницами.
6. Разделить авторские тезисы, короткие цитаты, пересказ и аналитические выводы.
7. Добавить ссылки из конспекта в соответствующую исследовательскую систему.
8. Перенести только проверенные проектные выводы в сравнительный слой.

## Правило авторских прав

В базе сохраняются библиографические сведения, короткие цитаты, пересказ, тематический конспект и ссылки на страницы. Полные тексты книг и длинные фрагменты не воспроизводятся в заметках.

## Статусы

| Статус | Значение |
|---|---|
| `incoming` | файл добавлен, обработка не начата |
| `indexed` | библиография и оглавление проверены |
| `reading` | идёт тематический конспект |
| `review` | конспект готов к проверке |
| `stable` | материал встроен в исследовательскую базу |
