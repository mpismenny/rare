# Джозеф Кэмпбелл: «Богини»

## Библиография

Передан русский текст издания: Джозеф Кэмпбелл. «Богини. Тайны женской божественной сущности». Издательство «Питер», 2019. Англоязычный оригинал `Goddesses: Mysteries of the Feminine Divine`, 2013, редактор Сафрон Росси.

## Зачем читать

- карта богинь в разных исторических слоях;
- интерпретация божественного женского у Кэмпбелла;
- влияние Марии Гимбутас;
- риск сведения разных традиций к универсальной модели Великой Богини.

## Очередь обработки

1. Извлечь оглавление.
2. Развести лекции Кэмпбелла и редакторскую рамку Росси.
3. Зафиксировать культурные источники по главам.
4. Сопоставить универсализирующие выводы с отдельными традициями.
