# Правила источников

## Иерархия

1. Первичные материалы автора или школы.
2. Научные исследования и официальная статистика.
3. Справочные материалы.
4. Публичные продукты, сайты и приложения.
5. Медиа и пользовательские обсуждения как материал для анализа языка аудитории.

## Для каждого утверждения

Отмечать:

- что именно подтверждает источник;
- дату обращения;
- принадлежит ли утверждение автору системы или исследователю;
- есть ли альтернативные трактовки;
- какие ограничения есть у материала.

## Для современных авторских систем

Сохранять:

- автора;
- дату появления;
- актуальное название;
- версию страницы;
- продуктовый контекст;
- отличия от ранних формулировок.

## Для собственной системы

Чужие архетипы, формулировки и визуальные решения не переносить напрямую. В базе они нужны для анализа паттернов, а не для копирования.

## Для локальной библиотеки книг

Использовать [[08_Источники/Библиотека книг/00_Как добавлять книги]].

Для каждой книги сохранять:

- библиографию и конкретное издание;
- исходный локальный файл;
- карту релевантных глав;
- страницы для каждого важного тезиса;
- различие между позицией автора, короткой цитатой, пересказом и аналитическим выводом;
- ограничения материала и альтернативные трактовки.
