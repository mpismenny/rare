# Требования после первого опорного прохода

## Рабочее позиционирование

`гипотеза`: «Редкие» становятся системой символической навигации по переходам для взрослых участниц. Система не определяет, кем человек является навсегда. Она помогает выбрать фигуру-союзницу для конкретной ситуации, заметить перегрузку и сделать малый шаг.

## Контракт MVP

| Слой | Требование |
|---|---|
| Вход | выбрать актуальную ситуацию за несколько минут |
| Фигуры | пять нейтральных рабочих образов |
| Выбор | одна основная фигура и при необходимости одна союзница |
| Контекст | ситуация важнее постоянного типа |
| Карточка | сцена, дар, перегрузка, ограничение, союзница, вопрос, действие и выход |
| Практика | обратимое действие на 5-15 минут |
| Проверка | отделить наблюдаемый факт от метафоры |
| Возврат | необязательный недельный обзор |
| Автономия | можно не согласиться, сменить фигуру или отказаться от карточки |
| Аудитория | первый полевой цикл только со взрослыми участницами |

## Что не включать в MVP

- тест;
- пожизненные типы;
- расчёт;
- прогноз;
- эзотерическое объяснение;
- заимствованные сказочные или мифологические персонажи;
- сложный визуальный мир;
- ежедневные обязательные задания;
- клуб;
- сертификацию проводников;
- мерч;
- работу с несовершеннолетними.

## Поля будущей фигуры

1. Собственная сцена.
2. Роль в мире.
3. Актуальная ситуация.
4. Дар.
5. Перегрузка.
6. Ограничение.
7. Союзница.
8. Внутреннее противоречие.
9. Один вопрос.
10. Одно действие.
11. Сигнал выхода.
12. Необязательный возврат.

## Ворота расширения

| Возможное расширение | Что должно быть доказано раньше |
|---|---|
| Шестая фигура | существующие пять не покрывают важную повторяющуюся сцену |
| Тест | свободный выбор фигуры уже работает и нужна навигация |
| Визуальная мифология | механика карточек различима и полезна |
| Месячный обзор | недельный возврат не воспринимается как давление |
| Группа | язык фигур поддерживает разговор без унификации опыта |
| Физический носитель | карточка нужна участницам после действия, а не только нравится |
| Проводники | метод полезен, воспроизводим и имеет этический кодекс |
| Клуб | есть подтверждённая потребность в длительной практике |

## Главная граница

Система должна оставлять участнице больше выбора после встречи с фигурой, чем было до неё.

## Правило раскрытия сложности

Каждый следующий уровень должен заслужить право появиться пользой предыдущего. Вывод зафиксирован в [[01_Исследование систем/01_Астрология/45_Уроки астрологии для расширения Редких]].

Любая трактовка хранит контекст версии: источник, визуальный носитель и границы применимости. Вывод зафиксирован в [[01_Исследование систем/02_Таро/45_Матрица сравнительного чтения старших арканов]].

Каждое новое правило получает паспорт версии: зачем оно добавлено, что меняет, как от него отказаться и какое полевое наблюдение подтверждает необходимость. Вывод зафиксирован в [[01_Исследование систем/03_Нумерология и матрица судьбы/44_Уроки нумерологии для расширения Редких]].

Каждое новое объяснение заканчивается малым наблюдаемым экспериментом или не добавляется вовсе. Вывод зафиксирован в [[01_Исследование систем/04_Дизайн человека/38_Уроки Human Design для расширения Редких]].

Любой ритм даёт право начать заново без долга за пропуск. Вывод зафиксирован в [[01_Исследование систем/06_Лунные практики/38_Уроки лунных практик для расширения Редких]].

Эмоционально сильный образ всегда возвращается в зону контроля и заканчивается действием. Вывод зафиксирован в [[01_Исследование систем/05_Манифестация желаний/33_Уроки манифестации для расширения Редких]].

Фигура описывает актуальную ситуацию и должна содержать выход. Она не становится пожизненным женским типом. Вывод зафиксирован в [[01_Исследование систем/07_Архетипы женственности/31_Уроки архетипов женственности для расширения Редких]].

Современный близкий референс переносится только на уровне абстрактной механики. Названия, фигуры, визуальный код, авторская мифология и продуктовая лестница заново проектируются из задачи и полевых сцен «Редких». Вывод зафиксирован в [[01_Исследование систем/08_Видимо-невидимо/24_Уроки Видимо-невидимо для расширения Редких]].
