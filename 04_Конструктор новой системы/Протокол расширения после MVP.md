# Протокол расширения после MVP

## Назначение

Документ определяет, как «Редкие» могут добавлять новые фигуры, правила и продуктовые слои после первого полевого цикла. Расширение является версией проверяемой гипотезы, а не наградой за красивую идею.

## Карточка запроса на расширение

| Поле | Что зафиксировать |
|---|---|
| ID версии | короткий идентификатор изменения |
| Предлагаемый слой | фигура, союзница, правило, ритм, группа, носитель или другой элемент |
| Повторяющаяся сцена | какой полевой эпизод не покрыт текущим MVP |
| Свидетельства | наблюдения, интервью и частота сигнала |
| Альтернатива без расширения | можно ли решить задачу существующей карточкой |
| Польза | что станет точнее или легче |
| Риск | долг, стыд, фиксация типа, копирование или лишняя сложность |
| Эксперимент | минимальная обратимая проверка |
| Сигнал успеха | что должно измениться наблюдаемо |
| Сигнал отказа | когда изменение откатывается |
| Граница оригинальности | как элемент объясняется без языка референсов |
| Решение | принять, отложить, отклонить или проверить повторно |

## Общие ворота

Любое расширение проходит семь ворот:

1. Есть повторяющаяся пользовательская сцена.
2. Текущий MVP не закрывает её достаточно хорошо.
3. Новое правило можно объяснить простым языком.
4. После объяснения есть малое наблюдаемое действие.
5. У слоя есть право отказа и сигнал выхода.
6. Элемент не требует копировать референс.
7. Проверка обратима и не создаёт долг участнице.

## Частные ворота

| Расширение | Что доказать раньше |
|---|---|
| Шестая фигура | повторяющаяся сцена не покрыта пятью фигурами |
| Обязательная союзница | основной выбор без второго образа регулярно недостаточен |
| Рефлексивный тест | свободный выбор понятен, но навигация действительно нужна |
| Постоянный тип | временная фигура не решает важную задачу, а риск ярлыка контролируется |
| Месячный обзор | недельный возврат воспринимается как поддержка |
| Уведомление | участницы сами просят напоминание, его можно отключить |
| Группа | разговор расширяет выбор без давления раскрытия |
| Визуальная мифология | фигуры различимы без декоративной оболочки |
| Физический носитель | карточкой пользуются после первого действия |
| Проводники | метод воспроизводим и имеет этический кодекс |
| Клуб | есть подтверждённая потребность в длительной практике |

## Паспорт значения

Если добавляется новое значение или трактовка, сохранить:

| Поле | Вопрос |
|---|---|
| Контекст | В какой ситуации это значение полезно? |
| Источник | Из какого полевого наблюдения оно возникло? |
| Версия | Когда и зачем оно добавлено? |
| Граница | Где значение перестаёт работать? |
| Действие | Что участница может проверить сама? |
| Выход | Когда карточку закрыть или заменить? |

## Красные линии

Расширение отклоняется, если:

- создаёт пожизненный ярлык;
- усиливает стыд или тревожную срочность;
- выдаёт метафору за факт;
- требует верить внешнему толкователю;
- копирует чужой персонаж, термин, визуальный код или продуктовый путь;
- удерживает участницу долгом за пропуск;
- добавляет сложность без новой наблюдаемой пользы.
