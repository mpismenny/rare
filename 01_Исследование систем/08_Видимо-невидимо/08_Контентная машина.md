# Контентная машина

## Наблюдение

Публичный Telegram-канал показывает, как одна система генерирует большое количество контента без постоянного введения новых сущностей.

## Матрица контента

| Ось | Примеры форматов |
|---|---|
| Архетип | Отдельный разбор каждого из семи образов |
| Сфера жизни | Продвижение, тексты, переговоры, деньги, найм, отдых |
| Ситуация | Праздник, покупка, конфликт, кризис, переход |
| Отношения | Пары и коллаборации архетипов |
| Тень | Искажение сильной стороны |
| Юмор | Узнаваемая бытовая сценка |
| Продукт | Типирование, клуб, курс, консультация, мерч |
| Путь | Этапы от невидимости к интеграции |

## Почему механика работает

Семь образов умножаются на ситуации, сферы и отношения. Получается большая контентная вселенная без необходимости каждый раз изобретать новый словарь.

## Что важно для «Редких»

Для первых фигур сразу проектировать матрицу:

1. Фигура × жизненная ситуация.
2. Фигура × переход.
3. Фигура × другая фигура.
4. Фигура × ритуал.
5. Фигура × продукт фонда.

Так можно проверить жизнеспособность мира до дорогой разработки.
