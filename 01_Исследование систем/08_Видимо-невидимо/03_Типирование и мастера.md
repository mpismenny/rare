# Типирование и мастера

## Что известно из публичных материалов

`факт`: система обучает сертифицированных мастеров индивидуальному типированию. Курс включает:

- общие принципы типирования;
- основы работы с закрытым онлайн-тестом;
- специфику опроса для каждого архетипа;
- интерпретацию ответов;
- эмоциональные и телесные реакции;
- рекомендации по маркетингу, переговорам, продвижению и имиджу;
- практику;
- экзамен из теоретической части и защиты типирования.

`факт`: публичное описание ограничивает сертификат индивидуальной работой с клиентами. Он не даёт права создавать курсы по системе.

## Ступени индивидуальной работы

| Шаг | Название | Задача |
|---|---|---|
| 1 | Типирование | Узнать архетип |
| 2 | Соединение с системой | Понять среду и подходящий «контракт» с ней |
| 3 | Стратегия продвижения | Выстроить видимость с учётом архетипа, среды и статуса |
| 4 | Финансы | Разобрать влияние, правила среды, утечки и модель заработка |
| 5 | Интеграция теней | Работать с теневыми проявлениями архетипа |

## Что важно для проектирования

1. Типирование должно иметь воспроизводимые критерии.
2. Одного теста может быть недостаточно.
3. Проводнику нужны обучение, практика и супервизия.
4. Право использования метода можно ограничивать.
5. У системы может быть слой специализаций.
6. Контекст влияет на рекомендацию сильнее, чем ярлык типа.

## Вопросы для дальнейшего изучения

1. Какие признаки считаются ключевыми для каждого архетипа?
2. Как тест соотносится с интервью?
3. Как разрешаются смешанные случаи?
4. Как проверяется качество рекомендаций мастеров?
5. Как меняется типирование при смене контекста?
