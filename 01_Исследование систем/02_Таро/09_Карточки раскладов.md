# Карточки раскладов

## Механика

Расклад задаёт каждой карте роль. Благодаря позиции несколько символов превращаются в структурированный рассказ, а не в набор независимых ассоциаций.

## Что изучать для «Редких»

1. Позиция делает символ точнее.
2. Малое число карточек снижает порог входа.
3. Вопрос важнее обещания предсказать будущее.
4. Сценарий должен заканчиваться действием в зоне контроля.
5. Повторный расклад не должен становиться способом избегать решения.
