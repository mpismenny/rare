# Карта второго цикла истории Таро

## Задача

Первый проход уже развёл игру, гадательную практику, оккультные соответствия и авторские колоды. Второй цикл добавляет карточки исторических узлов, чтобы поздние интерпретации не превращались в мнимый древний канон.

## Правило чтения

Для каждого узла различать четыре слоя:

1. сохранившийся объект;
2. исторический текст;
3. авторскую или школьную интерпретацию;
4. современный продуктовый вывод.

## Что уже видно

Историческая глубина Таро возникла не из одной схемы. Её создают несколько последовательных операций:

- сохраняется узнаваемый карточный каркас;
- новые мастера меняют визуальный язык;
- авторы добавляют интерпретационные таблицы;
- школы связывают карты с другими символическими системами;
- художницы превращают таблицу в самостоятельный мир образов;
- продукты добавляют повторяемые практики и обучение.

## Вывод для проектирования

Для новой системы недостаточно списка фигур. Нужны:

1. различимые ситуации;
2. ясный язык действий;
3. собственная визуальная грамматика;
4. правило перехода между состояниями;
5. маркировка того, где заканчивается наблюдение и начинается интерпретация.
