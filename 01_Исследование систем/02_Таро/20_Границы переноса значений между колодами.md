# Границы переноса значений между колодами

## Проблема

У разных колод сохраняется узнаваемая структура, поэтому возникает соблазн использовать одну таблицу значений для всех случаев.

Это допустимо только как предварительная гипотеза. Полный разбор должен учитывать конкретную колоду.

## Что можно переносить осторожно

| Слой | Что сохраняется | Оговорка |
|---|---|---|
| Структура | 22 старших и 56 младших арканов | У отдельных исторических вариантов есть отличия |
| Масти | Четыре группы | Названия и соответствия меняются |
| Числовой цикл | Туз и числа от двойки до десятки | Значения не сводятся к числу |
| Придворный слой | Четыре карты на масть | Названия и иерархия различаются |
| Расклад | Позиции и соседство | Способ синтеза зависит от школы |

## Что нельзя переносить автоматически

| Слой | Почему |
|---|---|
| Сцена RWS | В Marseille её может не быть |
| Заголовок Thoth | Он принадлежит конкретной сети соответствий |
| Номер VIII или XI | Сила и Правосудие меняются местами |
| Название придворной карты | Уровни RWS и Thoth не совпадают напрямую по словам |
| Перевёрнутое значение | Не каждая школа использует перевёрнутые карты |
| Астрологическая связь | Требует указания корпуса |
| Каббалистическая связь | Относится к герметической традиции |

## Пять вопросов перед чтением

1. Какая перед нами колода.
2. На какую традицию она опирается.
3. Что изменил автор.
4. Какой текст сопровождает колоду.
5. Какой метод чтения выбран.

## Пример: Тройка мечей

### Marseille

Вход:

- три меча;
- композиция;
- число;
- масть;
- соседство.

### RWS

Вход:

- сердце;
- три меча;
- облака;
- дождь;
- визуальный сюжет боли.

### Thoth

Вход:

- заголовок `Sorrow`;
- символическая композиция;
- Сатурн в Весах внутри корпуса;
- связь с системой соответствий.

Одно название карты не создаёт одно и то же чтение.

## Карточка переноса

Для любой производной колоды фиксировать:

| Поле | Вопрос |
|---|---|
| Источник | На какую колоду похожа структура |
| Изменение | Что добавлено или убрано |
| Символ | Какие детали меняют акцент |
| Текст | Есть ли авторский справочник |
| Соответствия | Сохраняются ли они |
| Метод | Как автор предлагает читать карты |
| Граница | Где старое значение больше не помогает |

## Вывод для «Редких»

`наблюдение`: символическая система может сохранять архитектуру и менять визуальный язык. Но новый образ требует собственной логики, а не косметической замены названий.
