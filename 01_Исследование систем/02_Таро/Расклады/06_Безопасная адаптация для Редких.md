# Безопасная адаптация для «Редких»

## Задача

Использовать карточную механику как способ рефлексии, а не гадание.

## Прототип из трёх карточек

| Позиция | Вопрос |
|---|---|
| Фигура | Какая сила может поддержать меня сейчас? |
| Перегрузка | Как её дар становится чрезмерным? |
| Шаг | Что я могу сделать за 5–15 минут? |

## Прототип из двух фигур

| Позиция | Вопрос |
|---|---|
| Союзница | Какая фигура помогает двигаться? |
| Баланс | Какая фигура не даёт силе стать чрезмерной? |
| Разговор | Как они могут поддержать друг друга? |

## Правила

1. Участница может не согласиться с карточкой.
2. Вопрос не предсказывает будущее.
3. Карточка не заменяет реального разговора.
4. Действие остаётся небольшим и безопасным.
5. Повторный выбор нужен для нового наблюдения, а не для снятия тревоги.
