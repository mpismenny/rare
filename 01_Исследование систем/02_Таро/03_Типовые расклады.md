# Типовые расклады

| Формат | Для чего нужен | Почему работает как продукт |
|---|---|---|
| Одна карта | Фокус дня или быстрый вопрос | Минимальный порог входа |
| Три карты | Прошлое, настоящее, будущее или ситуация, препятствие, действие | Появляется маленький сюжет |
| Расклад на отношения | Несколько позиций для участников и динамики | Отвечает на частый эмоциональный запрос |
| Расклад на выбор | Сравнение сценариев | Создаёт пространство для размышления |
| Кельтский крест | Развёрнутый анализ ситуации | Показывает глубину метода |
