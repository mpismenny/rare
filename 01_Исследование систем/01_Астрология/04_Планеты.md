# Планеты и светила

Рабочая карта функций внутри западной астрологии.

| Элемент | Тема внутри системы |
|---|---|
| Солнце | Ядро идентичности и воля |
| Луна | Эмоции, потребности, привычная реакция |
| Меркурий | Мышление и коммуникация |
| Венера | Ценности, симпатия, отношения, удовольствие |
| Марс | Действие, желание, конфликт |
| Юпитер | Расширение, смысл, возможности |
| Сатурн | Ограничение, структура, ответственность |
| Уран | Изменение, свобода, неожиданность |
| Нептун | Воображение, идеализация, растворение границ |
| Плутон | Сила, кризис, трансформация |

## Наблюдение

Набор функций превращает карту в язык внутренних частей. Человек может обсуждать противоречие не как личный дефект, а как взаимодействие нескольких сил.
