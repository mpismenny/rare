# Карта источников по астрологии

## Принцип

Один источник не может одновременно подтверждать:

- историю;
- астрономические факты;
- внутренние правила астрологической школы;
- научную достоверность астрологических утверждений;
- современную популярность и продуктовые механики.

Для каждого вопроса нужен подходящий тип материала.

## Источники по следующим итерациям

### Расчёт карты

Нужны:

- официальные астрономические справочники для координат и времени;
- документация Astrodienst по домам;
- отдельный источник по эфемеридам;
- сравнение основных систем домов.

### Расширенная интерпретация

Нужны отдельные корпуса для:

- эллинистической;
- средневековой;
- современной западной;
- психологической астрологии.

### Критика

Нужны:

- научные обзоры проверок астрологических утверждений;
- исследования эффекта Барнума;
- материалы о принятии решений и фатализме;
- исследования аудитории.

## Правило цитирования

В каждой новой заметке отмечать:

1. тип источника;
2. исторический слой;
3. школу;
4. что именно подтверждается;
5. что остаётся интерпретацией;
6. дату обращения.
