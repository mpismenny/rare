# Уроки астрологии для расширения «Редких»

## Что можно изучить как механизм

| Механика астрологии | Безопасный аналог для «Редких» |
|---|---|
| Простой первый вход | Выбрать одну актуальную ситуацию |
| Натальная карта как многослойный объект | Карточка фигуры с ясными полями |
| Транзит как изменяющийся контекст | Новая ситуация или наблюдаемый переход |
| Несколько часов возврата | Один необязательный недельный обзор в MVP |
| Синастрия как социальный сценарий | Союзница после основного выбора |
| Постепенное обучение | Новые уровни только после пользы предыдущих |
| Настройки метода | Ясные правила, что изменяет выбор карточки |

## Что нельзя переносить

- расчёт судьбы;
- пожизненный тип;
- ложную точность;
- ежедневный внешний советчик;
- тревожные уведомления;
- прогноз отношений;
- объяснение другого человека без его участия;
- бесконечное добавление сущностей ради удержания.

## Проверки перед расширением

1. Основная фигура понятна без дополнительного словаря.
2. Каждая фигура ведёт к различимому действию.
3. Союзница не размывает основной выбор.
4. Недельный обзор не создаёт чувство долга.
5. Участница может не согласиться с образом.
6. Пропуск не создаёт долг.
7. Новая карточка закрывает реальную повторяющуюся ситуацию.

## Главный вывод

Астрология сильна архитектурой, но новой системе не нужен её масштаб на старте. Для «Редких» важнее сохранить ясность: ситуация, фигура, действие, право отказаться и необязательный возврат.
