# Словарь ядра астрологии

| Термин | Краткое определение внутри системы | Зачем нужен |
|---|---|---|
| Натальная карта | Схема положения небесных тел в момент рождения | Главный персональный объект |
| Эклиптика | Видимый годовой путь Солнца по небесной сфере; проекция плоскости земной орбиты | Даёт основу зодиакальной координаты |
| Эфемериды | Рассчитанные положения небесных тел для выбранных моментов | Нужны для построения карты |
| Зодиак | Круг из 12 знаков | Даёт язык качеств |
| Тропический зодиак | Двенадцать равных секторов с отсчётом от точки весеннего равноденствия | Обычно используется в западной астрологии |
| Сидерический зодиак | Двенадцать равных секторов со звёздной привязкой | Обычно используется в джйотиш и отдельных западных школах |
| Планета | Символическая функция | Отвечает на вопрос «что проявляется» |
| Дом | Один из 12 секторов карты | Отвечает на вопрос «где проявляется» |
| Система домов | Правило деления карты на 12 домов | Может изменить номер дома для конкретного элемента |
| Куспид | Начало дома | Задаёт границу между домами |
| Аспект | Угловое отношение между элементами | Описывает взаимодействие |
| Орб | Допустимое отклонение от точного аспекта | Определяет, учитывается ли связь |
| Сходящийся аспект | Аспект, который приближается к точности | В отдельных школах указывает на формирующуюся связь |
| Расходящийся аспект | Аспект, который уже прошёл точность | В отдельных школах указывает на ослабевающую или прошлую связь |
| Асцендент | Восходящий знак на восточном горизонте | Входит в «большую тройку» |
| Десцендент | Противоположная асценденту точка | Связан с темой партнёрства |
| МС | Верхняя точка карты | Связана с публичностью и призванием |
| IC | Нижняя точка карты | Связана с домом и корнями |
| Стихия | Огонь, земля, воздух или вода | Группирует знаки по качеству |
| Модальность | Кардинальная, фиксированная или мутабельная | Описывает способ действия |
| Транзит | Текущее движение небесного тела относительно карты | Создаёт временной слой |
| Вторичная прогрессия | Метод символического соответствия «день за год» | Добавляет отдельный прогностический слой |
| Солнечная дуга | Сдвиг элементов карты на дугу прогрессированного Солнца | Даёт вариант дирекции |
| Профекция | Циклическая активация домов или знаков по годам жизни | Даёт годовой традиционный слой |
| Ретроградность | Видимое обратное движение небесного тела | Создаёт отдельную трактовку периода |
| Управитель знака | Планета, связанная со знаком в выбранной школе | Связывает элементы карты в сеть |
| Диспозитор | Управитель знака, в котором находится планета | Позволяет строить цепочки влияния |
| Эссенциальное достоинство | Оценка положения планеты по знаку и градусу в традиционной школе | Уточняет условия проявления планеты |
| Акцидентальное достоинство | Оценка положения планеты в конкретной карте | Добавляет контекст силы и условий |
| Лунные узлы | Точки пересечения орбиты Луны с эклиптикой | Добавляют отдельный расчётный и символический слой |
| Соляр | Карта ежегодного возвращения Солнца к натальному положению | Даёт годовой ритуал |
| Синастрия | Сопоставление карт двух людей | Создаёт сценарий совместимости |
| Композит | Символическая карта средних точек двух натальных карт | Даёт отдельный язык отношений |
| Хорарная астрология | Карта конкретного вопроса | Отвечает на отдельный тип задачи внутри традиции |
| Элективная астрология | Выбор момента начала действия | Создаёт отдельный прикладной сценарий |
| Мунданная астрология | Интерпретация коллективных и политических тем | Расширяет систему за пределы персональной карты |
| Аянамша | Поправка, используемая для сидерического отсчёта | Уточняет вариант сидерической карты |

## Очередь карточек

Каждый термин позднее получает отдельную карточку по шаблону [[Шаблоны/Элемент системы]].
