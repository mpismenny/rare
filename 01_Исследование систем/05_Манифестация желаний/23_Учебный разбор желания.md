# Учебный разбор желания

## Статус примера

Это синтетический учебный пример. Он показывает механику безопасного сценария, а не гарантирует результат.

## Исходное желание

> Хочу начать авторский проект и показать первый черновик.

## Разбор

| Шаг | Пример ответа |
|---|---|
| Значение | Хочу перестать откладывать важную для меня тему |
| Хороший результат | Через неделю существует черновик на одну страницу и один доверенный человек его прочитал |
| Факты | У меня есть две свободные встречи по 45 минут; структуры пока нет; интерес аудитории ещё не проверен |
| Зона контроля | Назвать тему, составить план, написать страницу, выбрать читателя, запросить обратную связь |
| Внутреннее препятствие | Я начинаю бесконечно улучшать структуру до появления первого текста |
| План «если, то» | Если я редактирую план дольше 20 минут, то открываю документ и пишу один абзац без правки |
| Малый шаг | Поставить в календарь первую встречу на 45 минут |
| Обзор | Через семь дней проверить: есть ли страница, была ли отправка, что стало понятнее |

## Что осталось вне контроля

- реакция другого человека;
- скорость роста проекта;
- будущий коммерческий результат;
- совпадения и внешние обстоятельства.

## Чем пример отличается от магического обещания

Образ будущего используется как ориентир. Он не считается причиной исполнения. Успех сценария проверяется фактом действия и новыми данными.
