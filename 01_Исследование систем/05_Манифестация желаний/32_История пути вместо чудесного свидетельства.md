# История пути вместо чудесного свидетельства

## Проблема свидетельства

Короткая история успеха легко превращает результат в доказательство ритуала. При этом исчезают:

- действия;
- ресурсы;
- помощь других людей;
- случайность;
- неудачные попытки;
- ограничения;
- привилегии.

## Две формы истории

| Чудесное свидетельство | История пути |
|---|---|
| «Я правильно подумала, и всё пришло» | «Я выбрала цель, попробовала шаг и скорректировала план» |
| Показывает совпадение | Показывает действия и ограничения |
| Усиливает обещание | Сохраняет неопределённость |
| Скрывает цену результата | Разрешает несовершенный путь |
| Создаёт давление на других | Возвращает агентность без обвинения |

## Шаблон безопасной истории

```text
Ситуация:
Желание:
Что было в зоне контроля:
Какое действие сделано:
Какие ресурсы помогли:
Что не получилось:
Что пришлось изменить:
Какой результат наблюдаем:
Что нельзя обобщать на всех:
```

## Проектный вывод

Для «Редких» кейсы должны рассказывать о процессе. Нельзя использовать исключительный результат как обещание для всех участниц.
