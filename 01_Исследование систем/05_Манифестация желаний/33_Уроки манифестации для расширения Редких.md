# Уроки манифестации для расширения «Редких»

## Что можно изучить как механизм

| Механика манифестации | Безопасный аналог для «Редких» |
|---|---|
| Эмоционально сильное желание | Актуальная ситуация, которая действительно важна |
| Образ результата | Короткое описание желаемого изменения |
| Препятствие | Перегрузка фигуры |
| План «если, то» | Одно обратимое действие |
| Материальный носитель | Карточка фигуры |
| История результата | Кейс пути с ограничениями |
| Обзор | Необязательная недельная проверка |

## Что нельзя переносить

- закон притяжения как доказанный механизм;
- вину за «неправильные мысли»;
- бесконечные ритуалы;
- streak;
- знаки как внешний приказ;
- обещание результата без действия;
- чудесные свидетельства как доказательство;
- подмену помощи практикой.

## Дополнение к правилам расширения

После предыдущих систем действуют четыре правила:

1. новый уровень заслуживает право появиться пользой предыдущего;
2. новое правило получает паспорт версии;
3. новое объяснение заканчивается малым наблюдаемым экспериментом;
4. любой ритм даёт право начать заново без долга.

Манифестация добавляет пятое:

5. эмоционально сильный образ всегда возвращается в зону контроля и заканчивается действием.
