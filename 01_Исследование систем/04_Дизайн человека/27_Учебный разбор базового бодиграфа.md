# Учебный разбор базового бодиграфа

## Ограничение примера

Ниже не рассчитанная карта человека, а синтетическая карточка результатов. Она нужна только для демонстрации порядка чтения. Для воспроизводимого разбора реальной обезличенной карты во втором цикле понадобятся источник исходных данных, версия калькулятора и снимок результата.

## Условные результаты

| Поле | Учебное значение |
|---|---|
| Тип | Генератор |
| Стратегия | Ждать отклика |
| Авторитет | Сакральный |
| Подпись | Удовлетворение |
| Тема ложного «я» | Фрустрация |
| Определённые центры | Сакрал и G-центр |
| Открытые центры | Остальные семь центров |
| Профиль | `2/4` |

`внутри-системы`: сакральный авторитет возможен у генератора при определённом сакрале и отсутствии определённого солнечного сплетения.

## Порядок чтения

### 1. Начать с типа

Первое правило должно помещаться в одну фразу: генератору предлагается ждать отклика, а не инициировать действие только из умственного решения.

### 2. Добавить авторитет

Второй слой уточняет наблюдение. В учебном примере внимание направлено на непосредственный телесный отклик в небольших безопасных ситуациях.

### 3. Назвать два маркера наблюдения

`внутри-системы`:

- удовлетворение читается как подпись;
- фрустрация читается как тема ложного «я».

Эти слова нельзя превращать в диагноз или доказательство того, что любое неприятное событие возникло из-за «неправильного» решения.

### 4. Показать центры

Для первого знакомства достаточно разделить:

- устойчиво закрашенные центры;
- открытые центры;
- один вопрос наблюдения для каждого выбранного центра.

Не нужно сразу вводить все ворота, линии и контуры.

### 5. Добавить профиль

Профиль `2/4` открывает ещё один слой языка. На первом чтении достаточно сказать, что профиль состоит из двух линий. Полное толкование стоит отложить до момента, когда пользователь понял тип и авторитет.

## Безопасный недельный эксперимент

1. Выбрать три небольших обратимых решения.
2. До действия записать вопрос и наблюдаемый отклик.
3. После действия записать фактический результат.
4. Отдельно отметить, где описание помогло, а где не совпало с опытом.
5. Не использовать эксперимент для медицинских, юридических или финансовых решений с высокой ценой ошибки.

## Что проверяет разбор

Хороший вводный разбор:

- не перегружает терминами;
- не обещает объективную диагностику;
- не объясняет несогласие «обусловленностью»;
- оставляет право отказаться от модели;
- переводит чтение в ограниченное наблюдение.
