# Профили как комбинации линий

## Кратко

Официальные материалы Human Design описывают профиль как комбинацию двух линий:

| Слой | Источник |
|---|---|
| Первая линия профиля | `Personality`, сознательная часть |
| Вторая линия профиля | `Design`, бессознательная часть |

Вместе они образуют одну из `12` комбинаций.

## Шесть линий

| Линия | Популярное название внутри системы |
|---:|---|
| `1` | Исследователь |
| `2` | Отшельник |
| `3` | Мученик или экспериментатор |
| `4` | Оппортунист |
| `5` | Еретик |
| `6` | Ролевая модель |

## Двенадцать профилей

| Группа | Профили | Геометрия `внутри-системы` |
|---|---|---|
| Right Angle | `1/3`, `1/4`, `2/4`, `2/5`, `3/5`, `3/6`, `4/6` | личная судьба |
| Juxtaposition | `4/1` | фиксированная судьба |
| Left Angle | `5/1`, `5/2`, `6/2`, `6/3` | трансперсональная тема |

## Зачем профиль нужен продукту

После типа пользователь получает более нюансированный персонаж:

- тип объясняет базовую стратегию;
- профиль добавляет стиль поведения;
- две линии создают внутреннее напряжение;
- геометрия добавляет сюжет;
- отдельный профиль становится темой курса или чтения.

## Риски

- превращать профиль в характерологический приговор;
- оправдывать поведение ярлыком;
- объявлять несогласие проявлением бессознательной линии;
- строить иерархию профилей;
- перегружать новичка предназначением до освоения базовой практики.

## Для «Редких»

Полезна фигура с двумя полюсами, которые создают узнаваемое напряжение.

Нельзя делать комбинацию пожизненным типом без права участницы выбрать другую оптику.
