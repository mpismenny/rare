# Этический чек-лист продукта Human Design

## Назначение

Чек-лист нужен для оценки чтения, карточки, калькулятора, приложения, курса или авторской адаптации.

## Позиционирование

- [ ] Ясно сказано, что Human Design представляет собой авторскую эзотерическую систему самопознания.
- [ ] Научные термины не выдаются за подтверждение классификации.
- [ ] Внутрисистемные утверждения визуально отделены от фактов и наблюдений.
- [ ] Сложность карты не используется как аргумент истинности.

## Автономия

- [ ] Пользователь может не согласиться с описанием.
- [ ] Несогласие не объясняется автоматически «обусловленностью».
- [ ] Тип не ограничивает профессию, отношения или жизненный выбор.
- [ ] Авторитет не снимает ответственности за решение.
- [ ] У пользователя есть право остановить углубление.

## Цена ошибки

- [ ] Для медицинских, юридических, финансовых и кризисных вопросов рекомендована профильная помощь.
- [ ] Телесный сигнал не объявляется безошибочным.
- [ ] Карта не ставит диагноз.
- [ ] PHS и медицински звучащие слои не заменяют доказательные рекомендации.

## Отношения и третьи лица

- [ ] Карта отношений не заменяет разговор и согласие.
- [ ] По карте не приписываются мысли и намерения другого человека.
- [ ] Данные рождения третьего лица не используются без разрешения.
- [ ] Решение о расставании не выводится из бодиграфа.

## Дети

- [ ] Ребёнок не фиксируется в ярлыке до формирования собственного языка.
- [ ] Карта не оправдывает отказ от наблюдения за реальными потребностями ребёнка.
- [ ] Родителям не обещают объективно определить судьбу, талант или ограничения.

## Приватность

- [ ] Объяснено, зачем нужны дата, точное время и место рождения.
- [ ] Есть понятный срок хранения данных.
- [ ] Пользователь может удалить данные.
- [ ] Персональные карты не публикуются по умолчанию.

## Ритуал возвращения

- [ ] Эксперимент начинается с небольших обратимых действий.
- [ ] Пропуск не создаёт вину.
- [ ] Транзиты не усиливают тревожную срочность.
- [ ] Уведомления можно отключить.
- [ ] Возврат происходит после наблюдения, а не из-за страха пропустить сигнал.

## Для «Редких»

Минимальная переносимая формула:

1. Дать простой язык для ситуации.
2. Предложить одно небольшое действие.
3. Назвать границу применимости.
4. Оставить право отказаться.
5. Вернуться к фактическому наблюдению через неделю.
