# Религиозные календари и границы заимствования

## Исламский календарь

Исламский календарь используется для религиозных целей. Он состоит из `12` лунных месяцев. Поскольку дополнительные месяцы для согласования с солнечным годом не добавляются, названные месяцы проходят через разные сезоны.

Начало Рамадана традиционно связывается с наблюдением растущего серпа. Конкретные способы определения даты могут различаться.

## Еврейский календарь

Еврейский календарь представляет собой лунно-солнечную систему. Лунные месяцы согласуются с солнечным годом через периодическое добавление месяца.

Календарь используется для определения религиозных соблюдений и ритуалов общины.

## Что важно не смешивать

| Контекст | Корректный вопрос | Некорректный перенос |
|---|---|---|
| Исламский календарь | как лунные месяцы регулируют даты религиозных практик? | назвать наблюдение серпа универсальным ритуалом намерения |
| Еврейский календарь | как лунно-солнечная структура удерживает праздники в сезонах? | использовать отдельные элементы как декоративную эзотерику |
| Современный дневник | как календарная точка помогает остановиться и записать наблюдение? | утверждать прямую преемственность от религиозного календаря |

## Граница заимствования

Религиозную практику нельзя превращать в свободно плавающий элемент продукта без:

- знания контекста;
- уважения к носителям традиции;
- понимания значения;
- ясной причины использования;
- оценки риска присвоения.

Для собственной системы безопаснее проектировать оригинальный светский ритм.
