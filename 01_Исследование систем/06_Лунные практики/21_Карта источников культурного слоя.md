# Карта источников культурного слоя

## Правило

Культурная и религиозная карта не должна опираться на случайный список ритуалов. Для каждого элемента фиксировать:

1. контекст;
2. период;
3. носителей;
4. тип источника;
5. границу адаптации;
6. риск универсализации.
