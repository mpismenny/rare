# Цикл как право начать заново

## Наблюдаемый ритм

NASA описывает восемь фаз Луны и повтор цикла примерно каждые `29,5` дня. Это астрономически наблюдаемый календарный каркас.

Символические задачи фаз относятся уже к культурному, религиозному или современному продуктовому слою.

## Почему повтор важен

Линейная система легко создаёт долг: если пользователь пропустил шаг, он будто отстал. Циклическая система допускает новый вход.

| Линейный интерфейс | Циклический интерфейс |
|---|---|
| Нужно продолжить с пропущенного места | Можно начать с текущей точки |
| Пропуск похож на неудачу | Пропуск не отменяет новый круг |
| Задачи накапливаются | Старый цикл можно завершить |
| Пользователь догоняет программу | Пользователь выбирает новый момент входа |

## Полезная формула

Цикл поддерживает автономию, если:

1. участие необязательно;
2. пропуск не создаёт долг;
3. задача не объявляется космической обязанностью;
4. новый круг позволяет изменить намерение;
5. дневник хранит опыт, а не оценку дисциплины.

## Риск

Цикл становится давлением, если:

- «неправильная» фаза запрещает обычное действие;
- пропуск ритуала объявляется потерянным шансом;
- каждый месяц требует новый продукт;
- календарь заменяет решение человека.

## Проектный вывод

Для «Редких» полезен не лунный календарь сам по себе, а право начать заново без долга. Недельный возврат MVP должен работать именно так.
