# Лунный и лунно-солнечный календарь

## Базовое различие

Синодический месяц длится примерно `29,5` дня. Двенадцать таких месяцев короче солнечного года. Поэтому календарям приходится выбирать, что именно сохранять.

| Тип | Принцип | Следствие |
|---|---|---|
| Лунный календарь | год состоит из синодических месяцев | месяцы могут смещаться относительно сезонов |
| Лунно-солнечный календарь | лунные месяцы периодически согласуются с солнечным годом | добавляются правила интеркаляции, например дополнительный месяц |
| Солнечный календарь | год привязан к движению Земли вокруг Солнца | фазы Луны не определяют структуру месяцев напрямую |

## Примеры

| Календарь | Тип | Ключевая особенность |
|---|---|---|
| Исламский | лунный | `12` месяцев не удерживаются в одном сезоне |
| Еврейский | лунно-солнечный | дополнительный месяц добавляется в определённые годы |
| Китайский | лунно-солнечный | лунные месяцы соединяются с солнечным годом и традиционными праздниками |
| Григорианский | солнечный | гражданский календарь не строится по фазам Луны |

## Почему это важно для базы

Слово «лунный календарь» может означать:

- календарную систему;
- таблицу фаз;
- астрологический календарь;
- список ритуальных рекомендаций;
- приложение с ежедневными подсказками.

Это разные продукты и разные уровни утверждений.

## Для «Редких»

Если будущей системе понадобится календарь, сначала нужно выбрать задачу:

1. Давать даты.
2. Создавать ритм возвращения.
3. Отмечать переходы.
4. Поддерживать дневник.
5. Собирать сообщество вокруг общих точек.

Не нужно имитировать сложность исторического календаря без продуктовой необходимости.
