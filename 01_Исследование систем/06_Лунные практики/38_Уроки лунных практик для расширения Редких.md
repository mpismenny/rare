# Уроки лунных практик для расширения «Редких»

## Что можно изучить как механизм

| Механика лунных практик | Безопасный аналог для «Редких» |
|---|---|
| Повторяемый цикл | Необязательный недельный обзор |
| Новый круг | Право начать заново без долга |
| Сжатие восьми фаз | Минимум опорных точек в MVP |
| Журнал | Память выбранного действия и результата |
| Общая дата | Необязательный повод для встречи или обзора |
| Календарная событийность | Только спокойное приглашение без FOMO |

## Что нельзя переносить

- космическую обязанность;
- запрет действовать в «неправильную» фазу;
- медицинские обещания;
- обязательную синхронизацию женского тела;
- тревожные окна;
- чужие религиозные ритуалы;
- стилизацию под древнюю универсальную традицию.

## Дополнение к правилам расширения

После предыдущих систем действуют три правила:

1. новый уровень заслуживает право появиться пользой предыдущего;
2. новое правило получает паспорт версии;
3. новое объяснение заканчивается малым наблюдаемым экспериментом.

Лунные практики добавляют четвёртое:

4. любой ритм должен давать право начать заново без долга за пропуск.
