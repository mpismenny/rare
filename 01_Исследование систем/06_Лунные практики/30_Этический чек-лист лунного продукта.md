# Этический чек-лист лунного продукта

## Позиционирование

- [ ] Астрономический факт отделён от символической трактовки.
- [ ] Понятно, какая школа или современный продукт предлагает ритуал.
- [ ] Культурная или религиозная практика не названа универсальной.
- [ ] NASA-данные не используются как доказательство эзотерического совета.

## Автономия

- [ ] Фаза ничего не запрещает.
- [ ] Пропуск не создаёт вину.
- [ ] Уведомления можно отключить.
- [ ] Пользователь может отказаться от календарной рамки.
- [ ] Несовпадение с трактовкой не объявляется личной ошибкой.

## Здоровье

- [ ] Календарь не ставит диагноз.
- [ ] Нет обещания обязательной синхронизации менструального цикла.
- [ ] Нет предсказания родов.
- [ ] Нет утверждения, что полнолуние неизбежно вызывает бессонницу или кризис.
- [ ] При высокой цене ошибки рекомендована профильная помощь.

## Культурные границы

- [ ] Назван контекст заимствованного элемента.
- [ ] Проверена причина использования.
- [ ] Оценён риск присвоения.
- [ ] Декоративный коллаж не выдан за древнюю традицию.
- [ ] Для собственной системы предпочтён оригинальный светский ритуал.

## Продуктовая механика

- [ ] Ритм поддерживает действие, а не тревогу.
- [ ] Возврат происходит после наблюдения.
- [ ] Ежедневный слой действительно нужен.
- [ ] Персонализация не создаёт ложное ощущение диагностики.
- [ ] Подписка не держится на страхе пропустить «сильный день».

## Для «Редких»

Безопасная формула:

1. Дать общий повод остановиться.
2. Предложить добровольный вопрос.
3. Выбрать малое действие.
4. Вернуться к фактам.
5. Разрешить начать заново или отказаться.
