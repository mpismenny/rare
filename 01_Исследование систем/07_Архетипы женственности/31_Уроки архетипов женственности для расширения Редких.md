# Уроки архетипов женственности для расширения «Редких»

## Что переносить

| Механика | Применение в «Редких» |
|---|---|
| временный образ | фигура выбирается для ситуации, а не навсегда |
| сцена | вход начинается с узнаваемого момента жизни |
| дар и перегрузка | ресурс показывается вместе с риском избытка |
| союзница | вторая фигура возвращает выбор, если первой недостаточно |
| переход | карточка ведёт к малому действию |
| выход | практику можно закончить без долга |

## Что не переносить

- чужие наборы богинь, героинь и архетипов;
- язык истинной женской природы;
- обязательный путь взросления;
- материнство как универсальный этап;
- тест как диагностику;
- толкование ведущего как единственно верное;
- клуб до проверки полезности карточки.

## Ворота расширения

| Расширение | Что должно быть доказано раньше |
|---|---|
| шестая фигура | повторяющаяся сцена не покрывается существующими пятью |
| союзница в интерфейсе | основная карточка уже понятна без второго образа |
| рефлексивный тест | свободный выбор работает, но участницам нужна навигация |
| визуальная мифология | сцены и различия фигур узнаваемы без декоративного мира |
| группа | язык фигур помогает говорить без давления раскрытия |

## Главное правило

Фигура описывает актуальную ситуацию и должна содержать выход. Она не становится пожизненным женским типом.
