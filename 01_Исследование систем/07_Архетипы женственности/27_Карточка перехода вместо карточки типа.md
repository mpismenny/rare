# Карточка перехода вместо карточки типа

## Сдвиг

Карточка типа отвечает на вопрос «какая я». Карточка перехода отвечает на вопрос «что происходит, какой ресурс нужен и как понять, что практика завершена».

## Минимальная карточка

| Поле | Назначение |
|---|---|
| Сцена | узнаваемый момент жизни без диагноза |
| Факты | что известно до интерпретации |
| Фигура | один временный образ |
| Дар | доступный способ действия |
| Перегрузка | наблюдаемый риск избытка |
| Союзница | дополнительная сила, если одной фигуры недостаточно |
| Вопрос | короткая рефлексия |
| Действие | обратимый шаг на 5-15 минут |
| Сигнал выхода | условие завершения |
| Возврат | необязательный обзор |

## Пример

Сцена: участница откладывает разговор, потому что хочет сформулировать всё идеально.

Фигура: `Голос`.

Дар: ясное обозначение позиции.

Перегрузка: бесконечная редактура вместо разговора.

Союзница: `Берег`, чтобы назвать границу одним предложением.

Действие: записать одну просьбу и один допустимый отказ.

Выход: после разговора карточка закрывается, даже если результат оказался неидеальным.

## Почему это важно

`гипотеза`: карточка перехода снижает соблазн собирать коллекцию красивых самоописаний. Её ценность проявляется в конкретной ситуации.
