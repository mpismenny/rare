# Безопасная адаптация архетипов

## Базовое решение

Для «Редких» использовать не неизменные типы женщин, а фигуры, с которыми можно встретиться в конкретной ситуации.

## Правила проектирования

1. Одна участница может узнавать себя в нескольких фигурах.
2. Фигура описывает ресурс и риск, а не полноценность человека.
3. Узнавание не требует согласия с тестом.
4. У каждой фигуры есть малое действие, а не только эстетика.
5. В любой момент участница может отложить образ, который ей не подходит.
6. Переход между фигурами является нормой.
7. Культурные референсы называются честно.
8. Символическая практика не выдаётся за лечение.

## Каркас безопасной карточки

| Поле | Вопрос |
|---|---|
| Сцена | В какой жизненной ситуации появляется фигура? |
| Дар | Что она помогает сделать? |
| Тень | Как её сила становится избыточной? |
| Ограничение | Чего фигура не умеет решить одна? |
| Союзница | Какая другая фигура помогает восстановить баланс? |
| Вопрос | Что участница может заметить в своём опыте? |
| Действие | Какой шаг занимает до 15 минут? |
| Выход | Как понять, что пора выбрать другую фигуру? |

## Вывод

Система станет убедительнее, если будет предлагать движение между фигурами, а не пожизненную классификацию.
