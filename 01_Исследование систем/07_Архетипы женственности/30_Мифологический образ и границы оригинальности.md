# Мифологический образ и границы оригинальности

## Три разных слоя

| Слой | Что фиксировать | Что нельзя смешивать |
|---|---|---|
| Источник | культура, сюжет, исторический контекст | современную трактовку не выдавать за древнее знание |
| Адаптация | автор, дата, выбранные акценты | авторский набор не объявлять универсальным каноном |
| Новая система | собственная сцена, название, визуальный код и практика | не копировать чужую мифологию и продуктовую формулу |

## Почему нейтральные фигуры полезны

Оригинальные рабочие фигуры снижают два риска:

1. Не требуется сжимать конкретный культурный образ до универсального женского типа.
2. Новая система не наследует чужой каталог персонажей вместе с его обещаниями и ограничениями.

## Матрица допуска

| Элемент | Можно изучать как механику | Нужен отдельный источник | Не переносить напрямую |
|---|---|---|---|
| переход между состояниями | да | нет | нет |
| дар и перегрузка | да | нет | нет |
| конкретная богиня или сказочная фигура | ограниченно | да | да |
| авторское название | только для анализа | да | да |
| визуальный символ | только для анализа | да | да |
| структура клуба | да, на абстрактном уровне | для датированного снимка | нет |

## Правило для «Редких»

Использовать оригинальные названия, сцены и символы. Если в будущем появится культурная отсылка, для неё создаётся паспорт происхождения и объяснение необходимости.
