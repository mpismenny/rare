# Позиции и слои схемы Ладини

## Граница

Эта карточка объединяет два публичных слоя:

1. Технические поля старого официального калькулятора.
2. Публичное описание текущего официального сайта и учебных программ.

Их нельзя считать исчерпывающим учебником метода. Между старой и текущей версиями возможны изменения.

## Предназначения в коде калькулятора

Для всех формул ниже используется редукция `R(x)` до диапазона `1–22`.

| Слой | Формула в публичном коде |
|---|---|
| Земное | `Earth = R(D + Y)` |
| Небесное | `Sky = R(M + B)` |
| Личное предназначение | `Personal = R(Earth + Sky)` |
| Род матери | `Mother = R(K2 + K4)` |
| Род отца | `Father = R(K1 + K3)` |
| Родовое предназначение | `Generic = R(Mother + Father)` |
| Духовное предназначение | `Spiritual = R(Personal + Generic)` |
| Планетарное предназначение | `Planetary = R(Generic + Spiritual)` |

## Карта здоровья старого калькулятора

Старый калькулятор показывает семь строк и итог. Каждая строка имеет три значения: физика, энергия и эмоции.

| Строка |
|---|
| Сахасрара |
| Аджна |
| Вишудха |
| Анахата |
| Манипура |
| Свадхистана |
| Муладхара |
| Итог |

`важно`: этот слой нельзя интерпретировать как медицинскую диагностику.
