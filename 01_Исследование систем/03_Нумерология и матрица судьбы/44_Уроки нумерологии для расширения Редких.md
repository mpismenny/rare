# Уроки нумерологии для расширения «Редких»

## Что можно изучить как механизм

| Механика нумерологии | Безопасный аналог для «Редких» |
|---|---|
| Короткий персональный вход | Выбор актуальной ситуации |
| Прозрачный расчёт | Понятное правило выбора фигуры |
| Визуальная карта | Карточка с различимой сценой |
| Повторы и пустоты | Наблюдение, какие ситуации возвращаются или не покрываются |
| Производные слои | Союзница и переход только после основного выбора |
| Временной цикл | Необязательный недельный обзор |
| Паспорт версии | Ясное описание каждого нового правила |

## Что нельзя переносить

- математическую маску судьбы;
- пожизненный вывод из даты рождения;
- бесконечные производные;
- детские ярлыки;
- диагностику здоровья;
- прогноз отношений;
- кармический долг как давление;
- обучение до проверки базовой пользы.

## Контрольный вопрос

Каждый новый слой должен отвечать:

> Какую повторяющуюся потребность участницы он закрывает?

Если ответа нет, слой не нужен.

## Что добавляет нумерология к уроку астрологии

Астрология показала необходимость постепенного раскрытия. Нумерология добавляет вторую дисциплину: любое правило расширения нужно хранить как версию, а не как вечную истину.
