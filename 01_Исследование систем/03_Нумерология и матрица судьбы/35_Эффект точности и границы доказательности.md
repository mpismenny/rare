# Эффект точности и границы доказательности

## Главная развилка

Нумерологическая формула может быть:

- прозрачной;
- повторяемой;
- технически корректно реализованной;
- визуально убедительной.

Из этого не следует, что её психологические, медицинские или прогностические трактовки истинны.

## Четыре слоя

| Слой | Пример |
|---|---|
| Исходные данные | дата рождения, имя |
| Арифметика | сложение цифр, таблица букв, редукция |
| Авторская схема | Life Path, линия семьи, предназначение, энергия года |
| Трактовка | описание характера, отношений, здоровья или будущего |

Первые два слоя можно пересчитать. Последние два требуют отдельного обоснования и не становятся доказанными только благодаря формуле.

## Почему результат ощущается точным

### Видимая арифметика

Человек сам может повторить несколько шагов. Это создаёт доверие к следующему тексту, хотя смысл числа не выводится из сложения математически.

### Персональные исходные данные

Дата рождения и имя кажутся глубоко личными. Результат воспринимается как сделанный специально для человека.

### Много слоёв

Чем больше показателей, ячеек, линий, циклов и сфер, тем выше вероятность найти узнаваемый фрагмент.

### Эффект Барнума

Американская психологическая ассоциация описывает эффект Барнума как склонность воспринимать общие описания личности или прогнозы как специально подходящие конкретному человеку.

### Подтверждающее смещение

Человек легче замечает совпадения и слабее учитывает несоответствия.

### Ретроспективная подгонка

После события неоднозначное описание легко перечитать как точное предсказание.

### Ореол древности и математики

Слова «Пифагор», «код», «формула», «матрица» и «диагностика» могут создавать дополнительное ощущение авторитета.

## Карта допустимых утверждений

| Формулировка | Допустимость |
|---|---|
| «По выбранной формуле получилось число `8`» | Да |
| «В этой школе число `8` связывают с такими темами» | Да |
| «Можно использовать описание как вопрос для рефлексии» | Да |
| «Формула математически доказала ваш характер» | Нет |
| «Пустая ячейка показывает болезнь» | Нет |
| «Совместимость доказала, что отношения обречены» | Нет |
| «Карта ребёнка определяет его профессию» | Нет |

## Защитные механики продукта

- показывать формулу;
- называть школу и автора;
- маркировать версию калькулятора;
- отделять арифметику от трактовки;
- не использовать диагностический язык;
- хранить поле «с чем я не согласна»;
- предлагать вопрос и действие вместо приговора;
- не делать выводов о третьих лицах;
- ограничивать тревожные повторные расчёты.

## Для «Редких»

Можно взять прозрачность. Нельзя брать ложную неизбежность.

Собственная система должна прямо говорить: образ или расчёт открывает вопрос, но не определяет человека.
