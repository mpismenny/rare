# Этический чек-лист нумерологического продукта

## Принцип

Чем убедительнее выглядит формула, тем яснее продукт должен показывать её границы.

## Чек-лист

### Прозрачность

- [ ] Названа конкретная школа или автор.
- [ ] Показаны входные данные.
- [ ] Показана формула.
- [ ] Указаны исключения редукции.
- [ ] Указана таблица букв.
- [ ] Указана транслитерация.
- [ ] Версия калькулятора датирована.

### Граница доказательности

- [ ] Арифметика отделена от трактовки.
- [ ] Результат не называется научной диагностикой.
- [ ] Формула не выдаётся за доказательство характера.
- [ ] Древняя генеалогия подтверждена источниками или маркирована как версия.
- [ ] Пользователь может не согласиться с описанием.

### Высокая цена ошибки

- [ ] Нет медицинских диагнозов.
- [ ] Нет обещаний лечения.
- [ ] Нет финансовых и юридических указаний.
- [ ] Нет прогноза неизбежной катастрофы.
- [ ] При необходимости показан путь к профильной помощи.

### Другие люди

- [ ] Совместимость не принимает решение за пару.
- [ ] Расчёт третьего лица не выдаётся за знание его мыслей.
- [ ] Нет отбора сотрудников по числам.
- [ ] Нет обвинений в адрес близких по карте.

### Дети

- [ ] Детская карта не превращается в фиксированный тип.
- [ ] Нет раннего выбора профессии по формуле.
- [ ] Нет ярлыков об интеллекте, здоровье или отношениях.
- [ ] Родителю предлагаются наблюдение и разговор, а не приговор.

### Ритм возврата

- [ ] Ежедневный показатель необязателен.
- [ ] Уведомления можно отключить.
- [ ] Пропуск не создаёт вину.
- [ ] Повторный расчёт не продаётся как снятие страха.
- [ ] Временной цикл заканчивается действием в зоне контроля.

### Данные и AI

- [ ] Собирается минимум персональных данных.
- [ ] Пользователь понимает, где хранятся имя и дата рождения.
- [ ] Историю можно удалить.
- [ ] Данные третьих лиц не используются без ясной причины и согласия.
- [ ] AI-текст маркируется как интерпретация, а не экспертное заключение.

## Красные линии

Остановить сценарий, если продукт:

- сообщает диагноз;
- обещает изменить судьбу платной процедурой;
- запугивает кармическим долгом;
- строит детский ярлык;
- предлагает расстаться или уволиться только по расчёту;
- скрывает формулу;
- использует псевдоисторическую легенду как доказательство.

## Для «Редких»

Система должна усиливать самостоятельность участницы. Если интерфейс делает авторскую метафору неоспоримой, он противоречит этой задаче.
