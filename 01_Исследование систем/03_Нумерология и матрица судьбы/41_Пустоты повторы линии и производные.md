# Пустоты, повторы, линии и производные

## Как малый ввод создаёт большую карту

Нумерологическая глубина возникает не только из словаря чисел. Система добавляет операции над результатом.

## Четыре генератора глубины

| Генератор | Пример | Что делает |
|---|---|---|
| Повтор | Несколько одинаковых цифр в психоматрице | Превращает количество в степень выраженности качества |
| Пустота | Отсутствующая цифра или показатель | Делает отсутствие отдельным сюжетом |
| Композиция | Линия таблицы `3 × 3` | Создаёт новый смысл из нескольких ячеек |
| Производная | Цикл, вершина или позиция графа | Порождает дополнительный уровень из уже рассчитанного значения |

## Почему это работает

- один вход даёт много точек узнавания;
- карта выглядит цельной;
- пользователь может возвращаться к отдельным зонам;
- новый жизненный вопрос активирует другой слой;
- обучение можно дробить на модули.

## Риск нефальсифицируемости

Чем больше производных, тем легче найти объяснение для любого опыта. Поэтому рядом с каждым слоем нужны:

1. название школы;
2. версия формулы;
3. правило получения результата;
4. граница трактовки;
5. запрет на диагностический язык.

## Проектный вывод

Для «Редких» полезна композиция, но не бесконечная производность. Пять фигур уже могут создавать глубину через:

- ситуацию;
- действие;
- перегрузку;
- союзницу;
- переход;
- недельное наблюдение.

Новый слой появляется только тогда, когда закрывает повторяющуюся потребность поля.
