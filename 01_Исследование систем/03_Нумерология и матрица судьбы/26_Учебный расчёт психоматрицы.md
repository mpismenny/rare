# Учебный расчёт психоматрицы

## Граница примера

Это воспроизводимый учебный расчёт одной современной реализации психоматрицы. Он не подтверждает историческую связь формулы с Пифагором и не является психологической диагностикой.

## Вымышленная дата

```text
17.06.1987
```

## Рабочие числа

| Шаг | Формула | Результат |
|---|---|---:|
| Первое число | `1 + 7 + 0 + 6 + 1 + 9 + 8 + 7` | `39` |
| Второе число | `3 + 9` | `12` |
| Третье число | `39 − 2 × 1` | `37` |
| Четвёртое число | `3 + 7` | `10` |

## Цифровой ряд

```text
Дата:     1 7 0 6 1 9 8 7
Рабочие:  3 9 1 2 3 7 1 0
```

Нули не заносятся в таблицу.

## Таблица

| `1` | `4` | `7` |
|---|---|---|
| `1111` | пусто | `777` |
| `2` | пусто | `8` |
| `33` | `6` | `99` |

## Линии

| Линия | Подсчёт количества цифр | Результат |
|---|---|---:|
| Цель `1 + 4 + 7` | `4 + 0 + 3` | `7` |
| Семья `2 + 5 + 8` | `1 + 0 + 1` | `2` |
| Привычки `3 + 6 + 9` | `2 + 1 + 2` | `5` |
| Самооценка `1 + 2 + 3` | `4 + 1 + 2` | `7` |
| Быт `4 + 5 + 6` | `0 + 0 + 1` | `1` |
| Талант `7 + 8 + 9` | `3 + 1 + 2` | `6` |
| Дух `1 + 5 + 9` | `4 + 0 + 2` | `6` |
| Темперамент `3 + 5 + 7` | `2 + 0 + 3` | `5` |

## Как использовать пример

### Допустимо

- проверить работу калькулятора;
- увидеть, как таблица создаётся из даты;
- сравнить версии формулы;
- заметить, где арифметика превращается в словарь;
- анализировать продуктовую механику.

### Недопустимо

- ставить диагноз по пустой ячейке;
- выбирать профессию по одной линии;
- оценивать здоровье по цифре `4`;
- делать выводы об интимной жизни по диагонали;
- использовать таблицу как доказательство характера.

## Главный исследовательский вывод

Психоматрица производит сильное ощущение персонализации за счёт трёх шагов:

1. одна знакомая дата;
2. видимая арифметика;
3. плотная визуальная карта с ячейками и линиями.

Формула прозрачна. Трактовка остаётся авторской.
