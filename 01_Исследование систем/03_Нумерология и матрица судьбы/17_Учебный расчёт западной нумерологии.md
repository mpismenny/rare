# Учебный расчёт западной нумерологии

## Граница примера

Это воспроизводимый учебный расчёт по публичным правилам школы Декоза. Он показывает арифметику и структуру показателей, но не подтверждает истинность трактовок.

## Исходные данные

Вымышленный пример:

```text
Имя при рождении: Nora Reed
Дата рождения: 17 июня 1987 года
Дата текущего цикла: 31 мая 2026 года
Алфавит: латинская таблица школы Декоза
```

## Базовые показатели

| Показатель | Результат | Откуда берётся |
|---|---:|---|
| Life Path | `3` | дата рождения |
| Birth Day | `17/8` | день месяца рождения |
| Sun Number | `5` | месяц + день |
| Expression | `8` | все буквы полного имени |
| Soul Urge | `8` | гласные полного имени |
| Personality | `9` | согласные полного имени |

## Как читать учебный профиль

### Шаг 1. Проверить вход

- имя записано латиницей;
- использовано имя при рождении;
- дата однозначна;
- школа названа;
- дата текущего цикла зафиксирована.

### Шаг 2. Пересчитать показатели

Каждое число должно иметь отдельную формулу. Если результат невозможно воспроизвести, калькулятор недостаточно прозрачен.

### Шаг 3. Отделить арифметику от смысла

| Слой | Пример |
|---|---|
| Факт о расчёте | `Expression = 8` по выбранной таблице |
| Трактовка школы | Восьмёрке приписываются темы силы, управления и материального результата |
| Вопрос для рефлексии | Где стремление к результату помогает, а где создаёт перегрузку? |
| Недопустимый вывод | Число доказывает профессиональную пригодность человека |

### Шаг 4. Проверить пересечения

В примере `8` повторяется в Birth Day, Expression и Soul Urge. Внутри школы это повод усилить тему. Для исследователя это также пример механики узнавания: повтор выглядит значимым и персональным.

### Шаг 5. Закончить вопросом, а не приговором

Расчёт можно использовать как повод для разговора. Нельзя использовать его для отбора, диагностики, обвинения или навязывания жизненного сценария.

## Что важно для «Редких»

Полезный перенос: прозрачный маленький шаг, который пользователь может повторить.

Опасный перенос: придать метафоре вид доказанной истины только потому, что перед ней стоит формула.
