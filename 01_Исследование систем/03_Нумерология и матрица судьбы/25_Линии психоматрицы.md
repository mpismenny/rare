# Линии психоматрицы

## Кратко

После заполнения девяти ячеек психоматрицы современная публичная реализация добавляет восемь линий: три горизонтали, три вертикали и две диагонали.

Значение линии технически определяется количеством цифр во входящих в неё ячейках.

## Восемь линий

| Линия | Ячейки | Название `внутри-системы` |
|---|---|---|
| Первая горизонталь | `1 + 4 + 7` | цель, целеустремлённость |
| Вторая горизонталь | `2 + 5 + 8` | семья |
| Третья горизонталь | `3 + 6 + 9` | привычки |
| Первый столбец | `1 + 2 + 3` | самооценка |
| Второй столбец | `4 + 5 + 6` | быт, деньги |
| Третий столбец | `7 + 8 + 9` | талант |
| Нисходящая диагональ | `1 + 5 + 9` | дух, духовность |
| Восходящая диагональ | `3 + 5 + 7` | темперамент |

## Как считать

Если в ячейке стоят две единицы, одна четвёрка и две семёрки:

```text
Линия 1 + 4 + 7 содержит 2 + 1 + 2 = 5 цифр.
```

Результат линии: `5`.

## Зачем нужны линии продукту

`наблюдение`: линии резко увеличивают глубину без новых исходных данных.

1. Сначала пользователь получает девять ячеек.
2. Затем узнаёт, что ячейки образуют сочетания.
3. Каждая линия добавляет новую сферу.
4. Появляется желание сравнить себя с близкими.
5. Калькулятор становится входом в подробный разбор.

## Критические границы

- линия «семья» не доказывает способность к браку;
- линия «деньги» не прогнозирует доход;
- линия «талант» не заменяет опыт и обучение;
- линия «темперамент» не даёт права делать интимные выводы о другом человеке;
- линия «дух» не создаёт иерархию людей.

## Для «Редких»

Полезен принцип: ограниченное число сущностей можно связывать в понятные композиции.

Нельзя переносить: рейтинги ценности человека и скрытые обещания точной диагностики.
