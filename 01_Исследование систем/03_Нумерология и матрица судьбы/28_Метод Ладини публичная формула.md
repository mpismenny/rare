# Метод Ладини: публичная формула

## Источниковая граница

По состоянию на 2026-05-31:

- текущий официальный сайт метода находится на [matricaladini.site](https://matricaladini.site/);
- старый официальный домен [matricaladini.ru](https://matricaladini.ru/) сообщает о переезде;
- на старом домене остаётся доступен [публичный калькулятор](https://matricaladini.ru/calculator/);
- вычислительное ядро калькулятора открыто загружается как [JavaScript-файл](https://matricaladini.ru/wp-content/plugins/matritsa/matritsa.js?ver=7.0).

Эта заметка описывает именно публичную техническую реализацию старого калькулятора. Учебные материалы текущего сайта могут включать расширения и обновления.

## Вход

```text
День рождения
Месяц рождения
Год рождения
```

## Редукция к диапазону от 1 до 22

В JavaScript калькулятора есть функция:

1. Если число `≤ 22`, оставить его без изменений.
2. Если число `> 22`, сложить цифры.
3. Повторять сложение цифр, пока результат не станет `≤ 22`.

Обозначим эту операцию как `R(x)`.

Примеры:

```text
R(17) = 17
R(1987) = 1 + 9 + 8 + 7 = 25 → 2 + 5 = 7
R(38) = 3 + 8 = 11
```

## Четыре базовые вершины

| Позиция | Формула |
|---|---|
| День | `D = R(день рождения)` |
| Месяц | `M = R(месяц рождения)` |
| Год | `Y = R(год рождения)` |
| Итог | `B = R(D + M + Y)` |

## Четыре угла

| Позиция | Формула |
|---|---|
| Между днём и итогом | `K1 = R(D + B)` |
| Между днём и месяцем | `K2 = R(D + M)` |
| Между месяцем и годом | `K3 = R(M + Y)` |
| Между годом и итогом | `K4 = R(Y + B)` |

## Центр и внутренние точки

| Позиция | Формула |
|---|---|
| Центр | `C = R(D + M + Y + B)` |
| Внутренний центр | `C2 = R(K1 + K2 + K3 + K4)` |
| Луч дня | `B1 = R(C + D)` |
| Луч месяца | `B2 = R(C + M)` |
| Луч года | `B3 = R(C + Y)` |
| Луч итога | `B4 = R(C + B)` |

Далее калькулятор строит дополнительные точки последовательным сложением соседних значений и применением `R(x)`.

## Что подтверждается

| Утверждение | Статус |
|---|---|
| Формула старого официального калькулятора доступна публично | подтверждается кодом |
| Все точки сводятся к диапазону от `1` до `22` | подтверждается кодом |
| Вход строится на дне, месяце и полном годе рождения | подтверждается кодом |
| Каждое полученное число имеет интерпретацию внутри метода | заявляется методом |
| Формула объективно диагностирует человека или судьбу | не подтверждено |

## Что нельзя делать

- называть код медицинской диагностикой;
- скрывать версию калькулятора;
- выдавать интерпретацию за математический факт;
- смешивать схему с психоматрицей;
- считать диапазон `1–22` доказательством тождества с Таро.
