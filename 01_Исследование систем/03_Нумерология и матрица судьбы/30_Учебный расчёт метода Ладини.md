# Учебный расчёт метода Ладини

## Граница примера

Это воспроизводимый технический расчёт по коду старого официального калькулятора. Он не является консультацией, диагностикой или доказательством истинности трактовок метода.

## Вымышленная дата

```text
17.06.1987
```

## Редукция

```text
R(x): складывать цифры числа, пока результат не станет ≤ 22.
```

## Базовые вершины

| Позиция | Формула | Результат |
|---|---|---:|
| День `D` | `R(17)` | `17` |
| Месяц `M` | `R(6)` | `6` |
| Год `Y` | `R(1987)` | `7` |
| Итог `B` | `R(17 + 6 + 7)` | `3` |

## Углы и центр

| Позиция | Формула | Результат |
|---|---|---:|
| `K1` | `R(D + B)` | `20` |
| `K2` | `R(D + M)` | `5` |
| `K3` | `R(M + Y)` | `13` |
| `K4` | `R(Y + B)` | `10` |
| Центр `C` | `R(D + M + Y + B)` | `6` |
| Внутренний центр `C2` | `R(K1 + K2 + K3 + K4)` | `12` |

## Внутренние лучи

| Позиция | Формула | Результат |
|---|---|---:|
| `B1` | `R(C + D)` | `5` |
| `B2` | `R(C + M)` | `12` |
| `B3` | `R(C + Y)` | `13` |
| `B4` | `R(C + B)` | `9` |

## Предназначения

| Слой | Формула | Результат |
|---|---|---:|
| Земное | `R(D + Y)` | `6` |
| Небесное | `R(M + B)` | `9` |
| Личное | `R(6 + 9)` | `15` |
| Род матери | `R(K2 + K4)` | `15` |
| Род отца | `R(K1 + K3)` | `6` |
| Родовое | `R(15 + 6)` | `21` |
| Духовное | `R(15 + 21)` | `9` |
| Планетарное | `R(21 + 9)` | `3` |

## Деньги и любовь

Код калькулятора выводит отдельные поля:

| Сфера | Результат примера |
|---|---:|
| Деньги | `8` |
| Любовь | `4` |

Полные промежуточные точки доступны в публичном JavaScript. Для базового понимания достаточно зафиксировать, что сферы являются производными от уже рассчитанных точек.

## Правильный способ использовать пример

### Можно

- сверить техническую реализацию;
- проверить калькулятор;
- понять рост сложности;
- анализировать визуальную и продуктовую архитектуру;
- сравнить версии метода.

### Нельзя

- делать вывод о здоровье;
- предсказывать судьбу;
- выбирать партнёра;
- делать вывод о ребёнке;
- использовать код как доказательство психологической точности.

## Главный исследовательский вывод

Одна дата превращается в десятки связанных точек. Это создаёт впечатление глубины и индивидуальности. Однако вся система зависит от одного авторского правила редукции и набора позиций.
